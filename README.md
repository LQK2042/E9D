## Điều khiển

  Phím                    Chức năng
  ----------------------- --------------------
  Esc                     Thoát chương trình
  Ctrl + kéo chuột trái   Di chuyển GIF
  Ctrl + →                Tăng tốc GIF
  Ctrl + ←                Giảm tốc GIF
  Ctrl + ↑                Tăng âm lượng
  Ctrl + ↓                Giảm âm lượng
  Ctrl + Chuột phải       Bật / tắt nhạc
